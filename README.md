# media_player

Простий десктопний медіаплеєр на Rust з GUI на `eframe/egui`.

Проєкт уміє:
- відкривати відеофайли через файловий діалог
- відтворювати відео й аудіо в одному потоці декодування
- ставити відтворення на паузу та продовжувати
- перемикати треки в плейлисті
- змінювати гучність
- перемотувати файл через seek-слайдер

## Технології

- `ffmpeg-next` — декодування відео та аудіо
- `rodio` — виведення аудіо
- `eframe/egui` — графічний інтерфейс
- `rfd` — вибір файлів через системний діалог

## Системні залежності

**Для опрацювання відео і аудіо потрібні тільки Linux-системні бібліотеки FFmpeg і ALSA.**  
Усі інші залежності проєкт підтягне через `cargo`.

### Fedora / Nobara

```bash
sudo dnf install ffmpeg-devel alsa-lib-devel pkgconf-pkg-config
```

### Ubuntu / Debian

```bash
sudo apt install pkg-config libasound2-dev libavcodec-dev libavformat-dev libavutil-dev libswscale-dev libswresample-dev
```

## Запуск

```bash
cargo run
```

Після запуску відкриється вікно плеєра. Додати файли можна через кнопку **`📂 Додати відео...`** у правій панелі.

## Керування

- `Space` — пауза / продовження
- `Prev` / `Next` — перемикання між файлами
- `🔊` слайдер — гучність
- нижній seek-слайдер — перемотування
- `Показати/Приховати плейлист` — перемикання правої панелі

## Примітка

Проєкт розробляється під Linux. Зовнішні системні залежності для медіаобробки тут зводяться саме до **FFmpeg** і **ALSA**.
